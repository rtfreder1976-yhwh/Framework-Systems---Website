# Framework Systems — Design System

Extracted from the live website (`site.css`, June 2026). The CSS is the source of
truth; `BRAND_GUIDELINES.md` in the repo root is v1.0 and now lags the live values.

## Foundations
- **colors.html** — full palette with hex + CSS variable + role
- **typography.html** — Playfair Display (headlines), DM Sans (body/UI), DM Mono (labels)
- **spacing.html** — container, radius, shadow, section padding, breakpoints

## Components
- **buttons.html** — primary (accent pill), secondary (ghost light/dark)
- **nav-header.html** — sticky navy header + `Framework.` wordmark
- **cards.html** — light card and dark-section card with tag pill
- **section-labels.html** — eyebrow, tag pills, values marquee
- **cta-band.html** — navy gradient CTA block
- **footer.html** — navy footer, mono copy, nav

## Brand quick reference
| | |
|---|---|
| Wordmark | `Framework.` — period in `#c4522a` |
| Headlines | Playfair Display 700/900 |
| Body / UI | DM Sans 300–700 |
| Labels | DM Mono, UPPERCASE, 0.1em+ tracking |
| Navy | `#0d1b2a` (dominant, 60–70% of layout) |
| Accent | `#c4522a` (actions only, never decorative) |
| Gold | `#c9a84c` (premium / faith accents) |
| Buttons | Pill, `border-radius: 999px` (live site) |

## Voice
Direct · earned · warm · plain-spoken · honest. Write like a competent operator who's
been where the reader is — not a consultant or salesperson. Second-person ("you").
Cite specific earned numbers, never vague claims.

**Avoid:** synergy, leverage, disrupt, innovative, cutting-edge, world-class, utilize,
empower, unlock, revolutionize, seamless, robust, holistic, game-changer.
